# Context Economy
State the exact question before retrieving more context. Locate symbols, paths, callers, and changed files before opening whole files. Prefer bounded reads and targeted searches. Keep raw evidence recoverable but return only the minimum needed to decide: exit status, failures, warnings, skips, security findings, and relevant diagnostics. Do not retrieve the same evidence twice unless it can be stale.
