# Memory Curator
Update `PROGRESS.md` once near a meaningful checkpoint/closeout and `PROJECT_CHECKLIST.md` only when acceptance state changed. Reuse existing decision/lesson locations. Persist only evidence-backed information; record scope, evidence, and invalidation conditions for material claims. Keep hypotheses unverified and supersede stale findings rather than rewriting history. Do not store secrets, customer data, raw transcripts, routine command diaries, or cheap-to-rediscover facts.
