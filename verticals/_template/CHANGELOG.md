# Changelog — `template`

All notable changes to this vertical's **schema and data**. Format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions are the
`schema_version` in `vertical.yaml`.

## What belongs here

This changelog tracks the things a downstream consumer cannot discover on their
own:

- entity types, properties, units and predicates added, renamed or removed;
- **identifier normalization changes** — these change join keys and are always
  breaking;
- source additions, rights reclassifications, status changes and takedowns;
- fact-selection or authority changes that alter which value is canonical;
- golden-record updates, **with the reason** (never "to make the test pass");
- indexability threshold changes.

A `schema_version` bump without an entry here is an incomplete change.
