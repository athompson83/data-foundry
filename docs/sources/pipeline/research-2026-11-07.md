## Correction (Codex review of `e67662b`)

The first NDC measurement generated fallback hyphenations that dropped a digit without checking it was zero padding, so some matches could be different packages (for example `00054317644` produced `00054-176-44`, which normalises to `00054017644`). `nadac.py` now generates only the 5-4-2 form and the zero-padded 4-4-2, 5-3-2 and 5-4-1 forms, asserts each normalises back to the original 11 digits, and counts a hit only when a returned `package_ndc` normalises to that NDC. The label measurement script is now committed as `nadac_label.py`. Re-measured on the same sample: NDC directory **169/200** (was 170) and drug label **48/60** (was 43). The registry, PROGRESS and this note carry the corrected figures.
