## Recalls widening (step 3)

One new member was added to a recall dataset: **`fda-company-announcements`** (FDA company recall announcements and press releases), a free-text member of
`food-and-health-recalls-global` beside the LIVE `fda-recalls` feed.

- The `datatables-data` URL returns an 88,228-byte XLSX of **1,089 announcements** (Date, Brand-Names, Product-Description, Product-Types, Recall-Reason-Description,
  Company-Name, Terminated Recall); the RSS feed carries the 20 newest with announcement text, which includes UPC and lot numbers (for example a Lidl gelato UPC and lot).
  `robots.txt` asks for a 30-second crawl delay, so only the XLSX and RSS are used.
- Linkage to openFDA enforcement reports (`evidence/2026-10-19/fda-announcements/link.py`, rule: same normalised firm, a shared product token of five or more letters, and an
  enforcement initiation or report date from 30 days before to 150 days after the announcement): **105 of 254** announcements dated 2026-01-01 or later match. Twelve random matches
  (`handcheck.json`) all agree on firm, product and date; that verdict is a read of the matching fields, not an independent source check. The other 149 were not separated into a missing
  enforcement report and a missing shared product token. A candidate join only: names never merge records (AGENTS.md rules 3 and 7).
- **Capture check:** `fda-recalls` acquires openFDA enforcement reports. The announcement text, which holds the company's own words, UPCs and lots, is not captured today, so this member
  is the fix; it is not built yet.
- **Still blocked** (retested today from this egress): ACCC `productsafety.gov.au` RSS and recall API HTTP 403; USDA FSIS recall API HTTP 403; the data.gov.au search found no ACCC recall
  dataset (four unrelated NSW documents); the NZ recalls sitemap answers 200. NHTSA's recall API and flat file answer 200 and Transport Canada's VRDB answers 200 (both already members of
  `vehicle-safety-recalls`).
