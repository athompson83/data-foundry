## Widening an existing dataset

Target: `consumer-product-recalls-north-america` (BUILDING; the CPSC and Health Canada members are deployed). Candidate: NHTSA equipment, child-seat and tire recalls (`nhtsa-recalls`, SCREENED, AMBER).

- Measured from the live `FLAT_RCL_POST_2010.zip`: 247,061 rows, 15,370 distinct campaigns (post-2010): 13,733 vehicle (V), 1,368 equipment (E), 200 tire (T), 69 child seat (C). So 1,637 campaigns are consumer-adjacent.
- Link to the live members: of 3,733 CPSC notices dated 2015 to 2026, only 2 mention NHTSA and 0 carry an NHTSA campaign-number token, so CPSC does not cite NHTSA campaigns. Health Canada's index cites none either (2026-10-18). With no declared identifier the NHTSA link can only be a reviewed candidate (brand + model + date), so NHTSA is **not added to `sources`** of the live dataset today. The registry entry `nhtsa-recalls` records the measurement; the NHTSA API terms (no bulk VIN lookup) remain AMBER.
- Capture check: the NHTSA flat files (POST_2010 and PRE_2010) are open https downloads but have no rights record yet, so they are not in `plans.json` (the snapshot workflow refuses a source without one). Gap recorded, not a live-dataset gap: no approved source is under-captured. Health Canada's file is already archived whole (2026-10-18); CPSC full-history source-ID reconciliation remains the open item from `docs/evidence/consumer-lifecycle-reconciliation-20261016.md`.
