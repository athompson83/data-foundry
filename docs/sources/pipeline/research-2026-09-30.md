## 3. Widening the existing datasets

`consumer-product-recalls-north-america` is BUILDING, and the validator requires every member of a BUILDING dataset to be
BUILDING or later and connected by confirmed joins, so a newly screened source cannot be attached to it yet.

UK OPSS (already a member of the SCREENED umbrella `home-product-recalls-global`) was re-measured as a candidate member:
the GOV.UK finder returns 3,734 notices from 2022-03-04, newest 2026-09-30T12:09Z. In the 600 most recent notices fetched
through `/api/content`, 155 contain a check-digit-valid GTIN. CPSC 2022-01..2026-09 has 1,800 recalls, 108 of them with a
valid GTIN (371 distinct). The overlap is **0**, which agrees with the round-3 result (0/1126) and means CPSC and OPSS do
not link declared by GTIN. So OPSS is not added to the North American dataset this run. Method and output: `screen_opss_gtin.py`, `opss_gtin.json`.

**Next widening candidate:** the non-consumer Health Canada categories already preserved in R2 (Food, Drugs, Medical
devices) can be linked to the LIVE FDA dataset only if a shared identifier exists; the HC index has none (fields are Title,
URL, Organization, Product, Issue, What you should do, Category, Recall class, Last updated, Archived), so any HC to FDA link
is a review candidate.
