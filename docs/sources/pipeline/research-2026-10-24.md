Findings worth keeping:

- **State Department codes are not ISO.** 63 of the 224 distinct State codes equal the ISO 3166 code of a different country (Israel `IS` is Iceland, China `CH` is Switzerland, Oman `MU` is Mauritius). A code join would silently attach the wrong country's advisory; the dataset links by reviewed name and alias, anchored on Canada's ISO codes.
- **Declared ids can be wrong.** About 21% of Open Library work-to-Gutenberg ids do not share a title prefix with the counterpart, and a hand check found one genuinely wrong link (OL "Siddartha" lists ebook 1, the Declaration of Independence). A declared id is verified against the counterpart before it is served.
- **Where the register of sources ran out.** USDA FSIS, ACCC and the USITC investigations pages answered HTTP 403; DONKI answered 503 and 429; the RASFF backend answered 405; the CDC active-investigations path answered 404 and the CDC outbreak pages are script-rendered; the BoE IADB and ECB press paths answered an error page or 404; the State Department copyright page answered 403, so its terms are unread.
- **Hand-check honesty.** The central-bank join is an automatic value agreement (the decided range equals the published range), not an independent hand check, and it is recorded that way. The SWPC to Kp tolerance (within one unit) is loose by construction.
