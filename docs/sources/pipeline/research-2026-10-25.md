Findings worth keeping:

- **Declared DOI coverage is thin on recent preprints.** Only 7.7 percent of the 300 most recently updated arXiv entries carry a DOI, so the arXiv to Crossref link covers the published subset, not the whole set. The dataset's `next_action` requires measuring the share over a full archive before sizing it.
- **Two agencies serve the same label at different times.** openFDA holds 127 of the 200 newest DailyMed set ids and the same SPL version for only 1, so the dataset keeps the version per source.
- **BLS blocks the default curl agent.** `www.bls.gov` returns Access Denied (even for robots.txt) to the default curl User-Agent and serves pages to the declared scout agent; recorded as a condition.
- **Terms not quoted this round.** Crossref, DailyMed, UniProt, PyPI and deps.dev pages did not yield a clean licence sentence from this egress; each stays AMBER with the quote as a precondition for RIGHTS_DETERMINED. Quoted today: O*NET (CC BY 4.0), BLS (public domain), arXiv (CC0 for metadata), openFDA (CC0), ClinGen (free of restriction).
