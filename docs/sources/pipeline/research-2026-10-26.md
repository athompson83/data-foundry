Findings worth keeping:

- **KEV is a flag, not a record.** All 1,756 KEV entries carry text, but NVD is the system of record for the description and severity, so the dataset keeps KEV as the exploitation fact per CVE.
- **OSV covers a minority of fresh CVEs.** Only 7 of the newest 30 KEV ids resolve, because OSV needs an affected package.
- **Earthquakes are weakly text-bearing.** Both catalogs are structured with a region label, so structuring value is scored 2 and the dataset queues behind higher-scoring ones.
- **Terms not quoted.** CISA, NVD, OSV and EMSC terms pages were not quoted this round; each is AMBER with the quote as a precondition for RIGHTS_DETERMINED. USGS is US government work (GREEN).
