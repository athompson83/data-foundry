NTSB Downloadable Aviation Datasets

This page contains downloadable NTSB aviation datasets. On April 5, 2027, NTSB will transition the downloadable aviation dataset to the Enterprise API platform, which will allow bulk retrieval of case information. We encourage you to begin using the GetCasesByDateRangeV2 API, which supports large date-range queries and bulk retrieval scenarios that were previously supported through the downloadable dataset.
