Welcome to the UKRI gateway to publicly funded research and innovation

Search for and analyse information on the latest innovative research in the UK

Below are some examples of how to search for things:
genome
searches for results with the word Genome
genome DNA
returns results containing the word Genome OR the word DNA.
genome AND DNA
returns results containing both the word Genome AND the word DNA. Important! Boolean operators like AND, NOT, OR must be capitalised.
"big data"
Surround with quotes will return things containing the exact phrase "Big Data"
"All Data"
Brings back the entire data set (a useful starting point for navigating facets)
