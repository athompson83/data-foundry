Data Foundry usage-invoicing benchmark evidence
Captured: 2026-08-26
Engine: PostgreSQL 16.15 (Ubuntu 16.15-0ubuntu0.24.04.1), x86_64
Dataset: 2,000,000 synthetic usage events; 200 synthetic tenants;
         1,398 synthetic keys; 4 synthetic verticals; 90-day window
Script: tooling/scripts/bench-usage-invoicing.ts
Safety: disposable local scratch database; no production data or credentials

All 13 migrations were applied before the run. The script ran each query five
times after ANALYZE and reported the best execution with the buffer counts from
that same execution.
